# Макеты домашних виджетов

Здесь лежит дизайн комплекта виджетов домашнего экрана: `*.html` — самостоятельные
страницы, которые открываются в любом браузере без сборки, `source/` — исходники
дизайн-канваса, из которого страницы выгружены.

## Что смотреть

Откройте [index.html](index.html) — оглавление со всеми страницами. Каждая страница
показывает один виджет во всех размерах, в светлой и тёмной темах, на «обоях»:
именно на обоях и проверяется читаемость оболочки.

| Страница | Содержимое |
|---|---|
| `Main.html` | обложка: курируемая раскладка на телефоне 412 dp |
| `Foundations.html` | оболочка, строка-вывод, шкала давления, кольца, серии, аватары, тип-рампа |
| `Resources.html` | ресурсы провайдеров, ярусы 2×2, 4×2, 4×4 |
| `QuotaBurn.html` | окна квоты Claude и темп сгорания |
| `MonthSpend.html` | расход за месяц и трафик |
| `DailyTokens.html` | токены по дням |
| `SharesModels.html` | доли провайдеров и топ моделей |
| `Tables.html` | последние вызовы и расход по API-ключам |
| `StatusSpeed.html` | статус шлюза и скорость |
| `DataStates.html` | пустой снимок, частичные данные, устаревший снимок, остановленный шлюз |

Размеры соответствуют сетке телефона 412 dp: 2×1 = 184 × 86, 4×1 = 380 × 86,
2×2 = 184 × 184, 4×2 = 380 × 184, 4×4 = 380 × 380.

## Что уже реализовано

Все двенадцать виджетов комплекта: ресурсы, окна квоты, темп расхода, токены по
дням, расход за месяц, трафик, доли провайдеров, топ моделей, последние вызовы,
расход по ключам, скорость, статус шлюза. Скриншоты настоящей реализации —
в [docs/images/widgets](../../images/widgets).

## Чем макеты отличаются от реализации

- **Интерактив.** В макетах тап по колонке, сектору или строке подменяет
  строку-вывод. В RemoteViews столько зон нажатия нет: виджет целиком открывает
  приложение, а поэлементный тап потребует перехода на Glance. Списки строк
  (пулы, модели, ключи, вызовы) при этом настоящие прокручиваемые — через
  коллекции RemoteViews, начиная с Android 12.
- **Подписи оси.** В макетах до семи подписей, в виджете три (начало, середина,
  «сегодня») — на домашнем экране больше не читается.
- **Радиус оболочки.** 24 dp вместо фирменных 16 — имитация системного клипа
  Android 12+; внутренние бары и карточки остались на 16.
- **Подписи под барами.** В макете под каждым баром ранжирования есть строка с
  провайдером и долей. В виджете её нет: шесть таких строк переполняют ярус 4×4,
  а провайдера несут знак и цвет бара.
- **Пунктир темпа.** В макете «темп расхода» рисует ровный темп от начала окна.
  В виджете пунктир короткий и показывает только направление — точный момент
  назван словами в подстрочнике.

## Как пересобрать

Страницы генерируются из исходников канваса:

```bash
cd source && node export-static.mjs ..
```

`build.mjs` собирает артборды канваса из `src/`-шаблонов (подставляет общий CSS и
JS-хелперы), `canvas.json` задаёт раскладку артбордов и заметки.
