# Журнал изменений

Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [0.2.0] — 2026-08-20

### Добавлено

- **Локальные модели.** Каталог, скачивание и хранилище моделей на устройстве;
  движок LiteRT-LM (`.litertlm`) и движок llama.cpp для GGUF (собирается из
  исходников сабмодулем, только arm64); встроенная Gemini Nano через системный
  AICore. Шлюз обслуживает локальные модели наравне с облачными.
- **Единый интерфейс.** Новая навигация Обзор / Ресурсы / Маршруты /
  Активность / Настройки, дизайн-система с полными светлой и тёмной темами,
  интерактивные графики. На Обзоре: QR-код адреса шлюза, блок «требует
  внимания», проверка связи одним тапом, «кто обслужит следующий запрос».
- **Реальные квоты провайдеров.** Адаптеры OpenRouter (баланс счёта), Codex
  (квота подписки ChatGPT), Claude (квота подписки двумя окнами), DeepSeek
  (баланс), Cursor (расход команды). Обновление раз в пять минут при
  работающем шлюзе; расход по данным поставщика учитывает запросы мимо шлюза.
- **Codex в один тап.** Браузерный OAuth (Authorization Code + PKCE, loopback
  1455), модели и реальная квота подтягиваются автоматически; CLI-сессии
  хранятся в Keystore и обновляются single-flight.
- **Уведомления о ресурсах.** Пять вычисляемых триггеров (низкий остаток,
  темп расхода, исчерпание раньше сброса и др.) с настройкой на каждый ресурс.
- **Двенадцать виджетов домашнего экрана.** Ресурсы, окна квоты, темп
  расхода, токены по дням, расход за месяц, трафик, доли провайдеров, топ
  моделей, последние вызовы, расход по ключам, скорость, статус шлюза; пять
  ярусов размера, светлая и тёмная темы, прокрутка списков с Android 12.

### Исправлено

- Запуск шлюза на занятом порту больше не роняет процесс.
- Проверка связи не падает на локальных моделях устройства.
- Баланс OpenRouter читается со счёта, отказы Cursor не проглатываются.
- Свободные ресурсы не занимают место в сетке Обзора; момент сброса Claude
  разбирается без java.time (совместимость с minSdk 24).

## [0.1.0] — 2026-08-18

Первый публичный выпуск форка.

- Локальный OpenAI-совместимый шлюз (Ktor CIO): `/v1/models`,
  `/v1/chat/completions` со стримингом, `/v1/embeddings`, Anthropic
  `/v1/messages`, Gemini `generateContent` и др.; виртуальная модель `auto`.
- Удалён «комбайн» апстрима QiTong (чат, память, персонажи, скиллы,
  групповой чат, веб-поиск) — оставлена только инфраструктура шлюза.
- Безопасность: loopback по умолчанию, защищённый LAN-режим с Bearer-токеном,
  секреты в Android Keystore (AES-256-GCM), `network_security_config`,
  закрыта дыра с отключённой проверкой TLS у прокси.
- Слой AI Resource Manager: квоты с честными источниками, цены и оценочная
  стоимость, бюджеты, resource-aware маршрутизация, история расхода и
  прогноз, первый домашний виджет, каркас OAuth.
- Полностью русский интерфейс, тема «врат», адаптивная раскладка.
